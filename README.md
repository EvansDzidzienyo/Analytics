# SQL and Data Analytics Portfolio

This repository contains SQL/database analysis work. The main project is **Celebrity Insights Analysis**, which combines a relational database design, SQL queries and a Power BI report.

## Featured project

### Celebrity Insights Analysis

- **Focus:** celebrity/entertainment data, including artist profiles, genres, awards, movies, songs and revenue.
- **Tools:** MySQL, SQL, Power BI and Excel.
- **Files:** [Project documentation](DataAnalysis/README.md), [table definitions](DataAnalysis/Tables.sql), [sample inserts](DataAnalysis/Insertions.sql), [analysis queries](DataAnalysis/Queries.sql), and [Power BI report](DataAnalysis/Capstone%20SQL.pbix).
- **Visual evidence:** screenshots in the `DataAnalysis/` folder.

The project documentation describes the database entities, analytical questions and report workflow. Please read the project-level README for schema details and known design limitations.

## How to explore

1. Review `DataAnalysis/README.md` for project scope and caveats.
2. Run the SQL scripts in order in a compatible MySQL environment, after reviewing the table definitions and sample data.
3. Open the Power BI file in Power BI Desktop to inspect the report.
